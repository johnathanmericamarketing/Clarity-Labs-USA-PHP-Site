# Notes for 2026-08-12

## Change ID: STORE-SUPPORT-20260812-001

**System:** Storefront
**Component:** Support
**Date:** 2026-08-12
**Title:** Shop /support page — public ticket submission (no login required)

**Problem**
Six existing links in the shop point to /support/ but the page did not exist, resulting in 404 errors. Customers who are locked out, can't sign up, or have order issues had no way to contact support without logging in. The main site has a working contact form (claritylabsusa.com/contact), but the shop needed its own public support endpoint for customers in these situations.

**Cause**
The shop /support page was not yet implemented. The backend API (POST /api/v1/support/ticket) existed and was proven to work via the main site's contact form, but the shop storefront had no public-facing support form to accept tickets from non-logged-in customers.

**Change Made**
- Created new file: `shop/support/index.php`
- Implemented a self-submitting form that:
  - Requires only age verification (via `age_gate_only()` — NO login required)
  - Accepts name, email, subject, topic dropdown, and message
  - Supports query string prefills: `?type=product_request`, `?subject=Order+123`
  - Maps topic dropdown options (question, product_request, bug, other) to API types (question, feature, bug, other)
  - Submits to POST /api/v1/support/ticket via the ClarityApiClient
  - Displays green success confirmation with ticket_number on success
  - Handles CSRF token properly via shared `clarity_session_start()` call (avoids 403 errors)
  - Includes honeypot field for bot detection

**Why This Change Was Made**
- Customers need a way to open support tickets without being logged in or able to sign up
- The storefront lacks a public support endpoint, causing the six existing links to 404
- The main site contact form proved the API works; the shop just needed the same interface
- This unblocks support access for locked-out, signup-failed, and non-customer users

**Files / Areas Affected**
- `shop/support/index.php` (new file)
- Git: commit 4d306b2

**Before**
